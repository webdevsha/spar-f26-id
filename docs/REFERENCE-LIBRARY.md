# Reference library — the documents this study reads

All of these are **public** documents, and they are committed here so the analysis pipeline (BoxCompute)
can read them directly from the repo rather than from someone's laptop.

Rule kept from before: **the repo holds the file only where we may redistribute it.** Every document
below is a public disclosure, a public regulation, or our own work. Nothing confidential, nothing
client-bound, nothing scraped behind a paywall.

## Why the set is worth looking at as a set

**Eight of the twelve bank documents are voluntary sustainability or annual reports.** That is not a
convenience — it is one of the study's findings: the evidence base for what banks are doing with AI rests
on disclosure choices, not on a reporting duty. A regulator cannot compel the series we are analysing
because no duty creates it.
