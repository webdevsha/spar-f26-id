# Reference library — what we read, where to get it (not redistributed here)

This repo is **public**. Third-party documents we rely on are cited and linked here, not copied into the
repository. That keeps provenance intact without redistributing someone else's PDF under our own name, and
without putting 209 MB of bank reports into git history permanently.

Rule of thumb: **if we did not write it, the repo holds the reference, not the file.** Local copies stay on
Shafira's machine (`docs/Data feed/`, git-ignored).

## Why this file exists

The tender question on any number we publish is *"where is that from?"* — and the answer must be a link a
reader can follow, not a file only we possess. This index is that link list. It is also the honest record
of how much of our evidence base rests on **voluntary corporate disclosures** (eight of the twelve local
documents are issuer sustainability or annual reports), which is itself one of the study's findings.
