Signal → trigger → shock

Move the sliders and watch the chain react. A signal is a number someone watches; a trigger is the threshold at which a named agency is supposed to act; the shock is what the workforce absorbs if the trigger is late or never pulled. This is the logic the project is trying to get right — the numbers are placeholders.

Demo model. Every figure below is illustrative — not a finding, not a forecast, not sourced. It exists so the shape of the chain is visible before real data lands.
