The chain from SPAR_Model_Proposal_V1.pdf run on the Indonesian anchor sector: finance & insurance, clerical support. Three scenario parameters (sL labour share, µ occupational mobility, ι matching curvature) on a 3×3 grid, with the two measured inputs (V vacancies, S searchers) taken from this lane's own data. Design notes: docs/MODEL-INDONESIA.md.

What this is, and what it is not

Demo, not a forecast. This is a live implementation of the proposal's mechanism, not a claim about Indonesia. Two of the four model inputs are placeholders in the current state — every number is tagged real / derived / placeholder / missing below, and the tags change what the panel says.

The proposal's discipline is estimate what the data can identify, calibrate what must be assumed, stress-test the assumptions that matter. So this page reports paths under assumptions — never a single headline number.

What it looks like with more data

The same engine, three inputs promoted from assumed to measured. Nothing about the mechanism changes — what changes is that the grid stops being illustration and starts being calibration, and the output can be defended.

Today — illustration

  • V is a slider over a number we invented.
  • µ is assumed, so the model cannot say whether Indonesian mobility is low or high.
  • sL uses the proposal's 0.60, which is a Philippine illustration.
  • The exposure flag currently identifies 1 of 288 postings as AI-related — keyword matching is not a measurement.
  • Result: a mechanism demonstration. Real, but not a finding about Indonesia.

With items 1, 2, 4 and 10 of the design note

  • V from a Karirhub back-series → a real vacancy trend, so ι gets tested against Indonesian data instead of asserted.
  • µ calibrated from Sakernas transitions → the model can say whether displaced clerical workers actually search elsewhere. This is the parameter most likely to differ from the Philippines.
  • sL read off national accounts for finance & insurance → the wage channel becomes an estimate, not a scenario.
  • Exposure from the ILO crosswalk onto KBJI occupation codes → the whole 331-row corpus becomes an exposure-weighted panel.
  • Result: a resilience map for Indonesia — which combinations give temporary reallocation and which give persistent unemployment.
